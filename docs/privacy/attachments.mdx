## Limits

- Images, PDFs and plain text files
- Up to **3 files** and **3 MB** per message

## How files are handled

- **Checked by content.** Files are verified by what they actually contain, not just their file name.
- **Used once.** A file is sent with your message and never stored. In saved chats, only the fact that a file was attached is remembered.
- **Text files** are masked like typed messages.
- **PDFs** are scanned. If a PDF contains a card number or IBAN, Proxi refuses it.
- **Images** cannot be scanned for sensitive data. Proxi warns you before you attach one, so check an image before sending it.

## Reopening an old chat

Because files are not stored, Claude cannot see an attachment again when you reopen a chat later. It is told the attachment is no longer available.
