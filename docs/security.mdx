---
title: "Security"
description: "How Proxi protects access to your chats."
---

<Card title="Sign-in required" icon="lock">
  Only signed-in users can chat. The server rejects every request without a valid session.
</Card>

<Card title="Chats are private to you" icon="user-lock">
  Saved chats are tied to your account. You can only see and delete your own.
</Card>

<Card title="Usage limits" icon="gauge">
  Each user is limited in how many messages they can send in a short time, with caps on message, file and reply size.
</Card>

<Card title="Browser protections" icon="shield">
  HTTPS only, a strict content policy, no embedding in other sites, and no camera or location access.
</Card>
