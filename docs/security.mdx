## Access control

- **Sign-in is required.** The chat only appears to signed-in users, and the server rejects every request without a valid session token.
- **Chats are private to you.** They are keyed to your account ID, and you can only list, open or delete your own.

## Abuse protection

- Each user can send 20 messages per 10 minutes.
- Message length, file count, file size and reply length are capped.
- Only a fixed list of models can be requested.

## Browser protections

- HTTPS only (HSTS)
- A strict Content Security Policy that limits which sites the app can load from or talk to
- No embedding of Proxi in other sites (clickjacking protection)
- No camera, microphone, location or payment access
- No referrer information sent to other sites

## Hosting

The app runs on Vercel, with its functions in the Frankfurt (EU) region.

## Reporting a problem

If you find a security issue, please contact the Proxi team directly instead of posting it publicly.
