title: "Choose a model"
description: "Auto, Haiku, Sonnet and Opus, and how to pick one."
---

Proxi uses **Auto** unless you pick a model. Auto checks how hard each message is and answers with the model that fits:

| Model | Best for |
|---|---|
| Haiku | Quick questions and fast answers |
| Sonnet | Most everyday requests |
| Opus | Complex work that needs careful reasoning |

## Pick a model yourself

Use the model menu next to the send button. Choose **Auto** to go back to automatic selection.

## See which model answered

Each reply's steps show which model wrote it.
