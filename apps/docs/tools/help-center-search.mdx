---
title: "Help center search"
description: "Proxi answers questions about itself from this help center."
---

For questions about Proxi itself, such as how privacy works or what a setting does, Proxi uses the `search_docs` tool to search this help center. The answer comes from the pages it finds, not from guesswork.

## What you see

- A help center step in the reply's list of steps.
- Numbered links to the pages used, labelled **Help center**, and a Sources list.

## Tips

- Ask in plain words, for example "How long are my chats kept?"
- If the answer isn't in the help center, Proxi should say so.
- To read the pages yourself, use the sidebar here.
