Besides answering from what it already knows, Proxi can use tools. A tool is a small action the assistant can take while writing a reply. Proxi uses five:

## Turn tools off

All tools are on by default. To stop Proxi from using one, open **Settings**, go to the **Tools** tab and uncheck it. Your choice applies to all your chats, from your next message. Turning a tool off doesn't delete anything it already did, such as memories you saved.

## You don't have to ask

Proxi decides when a tool helps. A simple question gets a direct answer with no tool.

## What tools can do

Most tools are read-only: they look things up and can't change anything for you. The exception is [Talk to a person](/tools/talk-to-a-person), which sends us an email, and only after you choose Send.

## See what Proxi did

Each reply shows a short list of its steps, such as searching the help center or the web.

## Sources

When a tool finds pages, the reply links to them in numbered links and a Sources list, so you can check them. When several lines in a row come from the same page, the link appears once, after the first of them.

## Limits

- Proxi can use tools in up to five rounds per reply.
- When a tool fails, Proxi tells you.
- What Proxi types into a tool is redacted first, like your messages. The email address you enter in the Talk to a person card isn't, so we can reply to you.
