---
title: "Check service status"
description: "Ask Proxi whether its tools are running."
---

Ask Proxi whether it is up, and it can use the `get_status` tool to check. The tool reports the status of Proxi's tool server, its version and how long it has been running.

## What it covers

It checks the tool server only. It doesn't test the chat app, sign-in or the AI provider, so a good result doesn't prove everything else is working.
