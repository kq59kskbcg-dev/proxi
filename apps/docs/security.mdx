---
title: "Security"
description: "How Proxi protects access to your chats."
---

<Card title="Rate limiting" icon="gauge">
  Each user can only send a limited number of messages per short period.
</Card>

<Card title="Content Security Policy" icon="shield-check">
  The browser only loads content from approved sources.
</Card>

<Card title="Encryption in transit" icon="lock">
  All traffic uses HTTPS.
</Card>

<Card title="Encryption at rest" icon="database">
  Stored data is encrypted by our providers, with AES-256 for chats and traces.
</Card>

<Card title="Vulnerability disclosure" icon="bug">
  Report security issues privately through [GitHub](https://github.com/kq59kskbcg-dev/proxi/security/advisories/new).
</Card>
