<Card title="Rate limiting" icon="gauge">
  Each user is limited in how many messages they can send in a short time, with caps on message, file and reply size.
</Card>

<Card title="Content Security Policy" icon="shield-check">
  The browser only loads scripts, styles and data from approved sources, and only connects to Proxi and its sign-in provider.
</Card>

<Card title="Encryption in transit" icon="lock">
  All traffic uses HTTPS, and browsers are told to only connect over HTTPS (HSTS).
</Card>
