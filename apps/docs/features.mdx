## Available now

| Feature | Details |
|---|---|
| ✅ Chat with Claude | Replies stream in as they are written, with Markdown formatting. |
| ✅ Model choice | Choose Opus 5.5, Sonnet 5.5 or Haiku 5.5. Each reply shows which model answered. |
| ✅ Saved chats | Search, reopen or delete your chats from the sidebar. |
| ✅ Attachments | Add images, PDFs and text files, up to 3 files and 3 MB per message. Drag and drop works. |
| ✅ Stop a reply | Stop a reply while it is being written. |
| ✅ Feedback | Rate any reply with thumbs up or down. |
| ✅ Help in chat | Ask Proxi about itself. It searches this help center and links to the pages it used. |
| ✅ Mobile layout | The app works on phones and small screens. |

## Planned

| Feature | Details |
|---|---|

| 🕒 Skills | Save instructions for tasks you repeat. |
| 🕒 Behavior | Set the tone, length and format of replies. |
| 🕒 Export chats | Download your chats. |
