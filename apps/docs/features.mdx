## Available now

| Feature | Details |
|---|---|
| ✅ Chat with Claude | Replies stream in as they are written. |
| ✅ Model choice | Choose Opus 5.5, Sonnet 5.5 or Haiku 5.5. |
| ✅ Sign-in required | Only signed-in users can chat. |
| ✅ Saved chats | Reopen or delete your chats from the sidebar. |
| ✅ Attachments | Images, PDFs and text files, up to 3 files and 3 MB per message. |
| ✅ Sensitive data redaction | Card numbers, IBANs, emails and phone numbers are redacted. |
| ✅ Feedback | Rate any reply with thumbs up or down. |
| ✅ Rate limiting | A limit on messages per user. |
| ✅ Mobile layout | The app works on phones and small screens. |
