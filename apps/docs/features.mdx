## Available now

| Feature | Details |
|---|---|
| ✅ Chat with Claude | Replies stream in as they are written, with Markdown formatting. |
| ✅ Model choice | Choose Opus 5.5, Sonnet 5.5 or Haiku 5.5. Haiku 5.5 is the default. Each reply shows which model answered. |
| ✅ Sign-in required | Only signed-in users can chat. The server rejects requests without a valid session. |
| ✅ Saved chats | Your chats appear in the sidebar so you can reopen or delete them. |
| ✅ Attachments | Images, PDFs and plain text files, up to 3 files and 3 MB per message. See [Attachments](/privacy#attachments). |
| ✅ Sensitive data redaction | Card numbers, IBANs, emails and phone numbers are redacted before reaching the model. See [Privacy](/privacy). |
| ✅ Feedback | Rate any reply with thumbs up or down. |
| ✅ Rate limiting | A per-user limit on how many messages you can send in a short time. |
| ✅ Mobile layout | The app works on phones and small screens. |
