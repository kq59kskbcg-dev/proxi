## How Proxi compares

How Proxi handles chats next to the ChatGPT and Claude apps, based on their published help pages in October 2026. Policies change, so check theirs for the latest. Proxi uses Claude through Anthropic's API, which has its own terms: Anthropic does not train on customer content sent that way.

### Normal chats

| | Proxi | ChatGPT app | Claude app |
|---|---|---|---|
| Not used to train AI models by default | ✓ | ✗ | ✗ |
| Anonymous to the model provider | ✓ | ✗ | ✗ |
| Names, addresses, card numbers, IBANs, emails and phone numbers removed before the model | ✓ | ✗ | ✗ |

The ChatGPT and Claude apps use consumer chats for training unless you turn that off in your settings. They also tie your chats to your account. Proxi never sends your name, email, account or IP address to Anthropic, and only the redacted messages reach it, so Anthropic can't tell who is writing. Names and addresses you type are removed in the same way, so what reaches Anthropic doesn't say who you are.

### Incognito chats

| | Proxi | ChatGPT app | Claude app |
|---|---|---|---|
| Never used to train AI models | ✓ | ✓ | ✓ |
| Kept out of your history and search | ✓ | ✓ | ✓ |
| Kept out of memory | ✓ | ✓ | ✓ |
| Kept out of the app's own records | ✓ | ✗ | ✗ |
| Anonymous to the model provider | ✓ | ✗ | ✗ |
| Names, addresses, card numbers, IBANs, emails and phone numbers removed before the model | ✓ | ✗ | ✗ |

The ChatGPT and Claude apps keep a copy of an incognito chat for up to 30 days for safety, even though it stays out of your history, memory and training. Proxi keeps none. The reply is written by Claude, so Anthropic's own terms still apply to that request, and Anthropic may keep API requests for a short time. Incognito chats never save to memory and don't use your saved memories.

Sources: OpenAI's [Temporary Chat](https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt) and [data usage for consumers](https://help.openai.com/en/articles/7730893-data-usage-for-consumers) pages, and Anthropic's [incognito chats](https://support.claude.com/en/articles/12260368-use-incognito-chats) page.

## Subprocessors

These providers process data on Proxi's behalf.

| Provider | Purpose | Data processed | Location |
|---|---|---|---|
| Anthropic | Generates replies with Claude, and runs web searches | Redacted messages, attachments and search queries | US |
| Clerk | Sign-in and sessions | Account email and name | US |
| Neon | Database for saved chats | Redacted chats | EU (Frankfurt) |
| Langfuse | Monitoring, tracing and feedback | Redacted messages, usage and feedback | EU |
| Resend | Emails us when you ask to talk to a person and choose Send | The summary shown in the card and the email address you enter | US |
| Vercel | Hosting | App requests | EU (Frankfurt) |
