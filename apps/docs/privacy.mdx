## How Proxi compares

How Proxi handles chats next to the ChatGPT and Claude apps, based on their published help pages in October 2026. Policies change, so check theirs for the latest. Proxi uses Claude through Anthropic's API, which has its own terms: Anthropic does not train on customer content sent that way.

**Incognito chats**

| | Proxi | ChatGPT app | Claude app |
|---|---|---|---|
| Kept out of your history and search | ✓ | ✓ | ✓ |
| Kept out of memory | ✓ | ✓ | ✓ |
| Never used to train AI models | ✓ | ✓ | ✓ |
| No copy kept by the app itself | ✓ | ✗ | ✗ |

Proxi has no memory feature, so there is nothing for an incognito chat to leave out. The ChatGPT and Claude apps keep a copy of an incognito chat for up to 30 days for safety, even though it stays out of your history, memory and training. Proxi keeps none. The reply is written by Claude, so Anthropic's own terms still apply to that request, and Anthropic may keep API requests for a short time.

**Normal chats**

| | Proxi | ChatGPT app | Claude app |
|---|---|---|---|
| Not used to train AI models by default | ✓ | ✗ | ✗ |

The ChatGPT and Claude apps use consumer chats for training unless you turn that off in your settings.

**What Proxi adds to every chat**

| | Proxi | ChatGPT app | Claude app |
|---|---|---|---|
| Card numbers, IBANs, emails and phone numbers removed before the model | ✓ | ✗ | ✗ |

Sources: OpenAI's [Temporary Chat](https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt) and [data usage for consumers](https://help.openai.com/en/articles/7730893-data-usage-for-consumers) pages, and Anthropic's [incognito chats](https://support.claude.com/en/articles/12260368-use-incognito-chats) page.

## Subprocessors

These providers process data on Proxi's behalf.

| Provider | Purpose | Data processed | Location |
|---|---|---|---|
| Anthropic | Generates replies with Claude, and runs web searches | Redacted messages, attachments and search queries | US |
| Clerk | Sign-in and sessions | Account email and name | US |
| Neon | Database for saved chats | Redacted chats | EU (Frankfurt) |
| Langfuse | Monitoring, tracing and feedback | Redacted messages, usage and feedback | EU |
| Vercel | Hosting | App requests | EU (Frankfurt) |

## Limitations

Proxi is a personal project. These are known tradeoffs made to keep it free to run.

- **Redaction covers structured data only.** Proxi uses pattern matching to redact cards, IBANs, emails and phone numbers, but can't catch names or addresses. A company could add a small self-hosted model for those.
- **Observability runs on Langfuse Cloud.** Redacted conversations are stored by Langfuse in the EU. A company could self-host it to keep that data in its own infrastructure.
- **Images and scanned documents aren't checked.** Proxi checks the text in PDFs and blocks files with card numbers or IBANs, but can't read text inside images or scans. A company could add OCR to check them before sending.
