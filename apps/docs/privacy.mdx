<Card title="Sensitive data redaction" icon="eye-slash">
  Card numbers, IBANs, emails and phone numbers are redacted before reaching the model, the logs or the database.
</Card>

<Card title="Attachments are never stored" icon="paperclip">
  Files are used for one request only. Text PDFs containing card numbers or IBANs are refused. Emails and phone numbers inside PDFs are not redacted.
</Card>

## Subprocessors

These providers process data on Proxi's behalf.

| Provider | Purpose | Data processed |
|---|---|---|
| Anthropic | Generates replies with Claude | Redacted messages, plus attachments sent with them |
| Clerk | Sign-in and sessions | Account details such as your email and name |
| Neon | Database for saved chats | Redacted chats, tied to your account ID |
| Langfuse (EU) | Monitoring, tracing and feedback | Redacted message text, model used, token counts, account ID, thumbs up or down |
| Vercel | Hosting (functions in Frankfurt, EU) | Requests to the app and its API |
| Cloudflare | Bot protection during sign-in, through Clerk | Browser details needed to check the sign-in is human |
| Mintlify | Hosts this help center and its search | Search queries the assistant sends when looking up help articles |
